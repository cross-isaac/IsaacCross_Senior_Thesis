# 09_Kovachy_Lab — Prior training work (Kovachy lab)

Work done in Prof. Tim Kovachy's lab before/alongside the thesis project. This is where
the Nichrome-mica heater design originated (built for a strontium vapor cell, later
adapted for the beam source — thesis Sec. 3.5) and where core skills (vacuum assembly,
CAD, heater/electronics design) were learned. Kept separate because it is not part of
the thesis apparatus itself.

- **`Heating Data ...pdf`** + Notion export folder — Sr cell heating test data (Aug 2023).
- **`Copper Piece/`** — copper mount/cap CAD designed for the Kovachy experiment
  (v1 and `2.0/`).
- **`first MOT/`** *(git-ignored — several hundred MB of CAD)* — full SolidWorks assembly
  of the Kovachy lab's first MOT (chamber, coils, atom source, supports).
- **`WURG Research Report 2023.pdf`** — report for the funded 2023 Winter URG
  (the proposal itself is in `08_.../Proposals`).
- `console.log`, `SWActivateRequest...txt` — SolidWorks licensing/log artifacts (inert).
